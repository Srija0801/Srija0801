## Featured Projects

###  [iStayz – Hotel Reservation System](https://github.com/Srija0801/iStayz)
A full-stack hotel reservation platform built using the MERN stack.

- JWT-based user authentication.
- Hotel search using SerpApi.
- Booking management and Razorpay payment integration.
- Interactive maps using Leaflet and OpenStreetMap.
- Cloudinary image storage.

**Tech:** React.js, Node.js, Express.js, MongoDB, JWT, Razorpay.

###  [Swapify – Skill Exchange Platform](https://github.com/Srija0801/Swapify)
A platform that connects users to share skills and learn from each other.

- User authentication and skill management.
- Real-time messaging using Socket.io.
- MongoDB database integration.
- Admin moderation.

**Tech:** React.js, Node.js, Express.js, MongoDB, Socket.io.


###  [Large-Scale Network Traffic Analysis](https://github.com/Srija0801/Large-Scale-Network-Traffic-Analysis-Using-HDFS-Pig-and-Hive)
A big data project focused on processing and analyzing large-scale network traffic datasets.

- Distributed data storage using HDFS.
- Data processing using Apache Pig.
- Data analysis using Apache Hive.

**Tech:** Hadoop, HDFS, Apache Pig, Apache Hive.
